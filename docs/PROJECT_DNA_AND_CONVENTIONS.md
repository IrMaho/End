## 🌟 Why Project DNA Matters

When AI agents generate code without architectural context, they introduce subtle convention drift:
- Mixing `camelCase` and `snake_case` in the same codebase.
- Mixing exceptions/panics with explicit `Result<T, E>` / `!T` patterns.
- Bypassing repository/pipeline clean architecture layers.
- Violating concurrency invariants (e.g. sharing mutable state instead of message channels).

The **Project DNA Engine** (`end dna`) mines the entire codebase to extract the project's architectural genome and enforces 100% adherence on AI-generated patches.
