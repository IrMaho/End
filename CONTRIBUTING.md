# Contributing to End Language 👑

Thank you for your interest in contributing to **End**, the native programming language for Autonomous AI Agents and Software Architects!

---

## 🌟 The 12 Immutable Principles of End Core

All contributions to the End language compiler (`endc`) and standard library must adhere to these 12 core design principles:

1. **Native:** Compiles to zero-overhead machine code (no forced Garbage Collection).
2. **Fast:** Millisecond compilation and check turnaround times.
3. **Readable:** Syntax optimized for humans as reviewers/architects.
4. **Explicit:** No hidden control flow or implicit type conversions.
5. **Deterministic:** 100% predictable execution behavior.
6. **Modular:** "Everything is a Module" with micro-modularity support.
7. **Composable:** Single mental model across UI, systems, and backend.
8. **Zero-Cost Abstraction:** What isn't used isn't paid for at runtime.
9. **Compile-Time Programmability:** First-class metaprogramming.
10. **Machine/Agent Inspectable:** Machine-first introspection (END-AIP).
11. **Hardware Accessible:** First-class CPU/GPU intrinsics, assembly, and register-level control.
12. **Extensible:** Allows custom domain profiles without breaking the core language semantics.

## 🛡️ Production Quality Barriers & Branch Protection Policy

The `main` branch is protected by an **enforced production quality contract**. No pull request may be merged without passing all **8 required CI quality gates**:

| Gate # | Gate ID | Name | Verification Command | Enforcement |
|:---|:---|:---|:---|:---|
| **1** | `G1_CARGO_TEST` | Rust Compiler Test Suite | `cargo test --manifest-path endc/Cargo.toml --lib` | **Strict Fail-Closed** |
| **2** | `G2_GOLDEN_RUNNER` | Golden Integration Suite | `cargo run --manifest-path endc/Cargo.toml --bin golden_runner` | **Strict Fail-Closed** |
| **3** | `G3_STDLIB_MATRIX` | Standard Library Matrix | `cargo run --manifest-path endc/Cargo.toml --bin stdlib_matrix_runner` | **Strict Fail-Closed** |
| **4** | `G4_BENCH_INTEGRITY` | Benchmark & Anti-Fraud | `cargo run --manifest-path endc/Cargo.toml --bin bench_runner -- --all` | **Strict Fail-Closed** |
| **5** | `G5_DIFFERENTIAL_TESTS` | Differential Parity | `cargo run --manifest-path endc/Cargo.toml --bin golden_runner -- --differential` | **Strict Fail-Closed** |
| **6** | `G6_ADVERSARIAL_TESTS` | Adversarial Proof & Diagnostics | `cargo test --manifest-path endc/Cargo.toml --lib -- agent::tests` | **Strict Fail-Closed** |
| **7** | `G7_DOCS_EXAMPLES` | Documentation Executability | `cargo test --manifest-path endc/Cargo.toml --test docs_examples` | **Strict Fail-Closed** |
| **8** | `G8_FINAL_AUDIT` | Evidence Audit & Report | `cargo run --manifest-path endc/Cargo.toml --bin final_evidence_auditor` | **Strict Fail-Closed** |

### No Fake Success Policy
- Silent skips, downgraded assertions, or `continue-on-error` are strictly forbidden.
- Any discrepancy between claimed capabilities and executable reality immediately fails the evidence audit.
- Releases require a clean, verifiable `production_readiness_report.json` generated by Gate 8.

## 🛠️ Development Setup

### Prerequisites
- **Rust Toolchain:** `rustc` and `cargo` (edition 2021 / latest stable)
- **LLVM Toolchain:** LLVM 18+ (`clang.exe` and `llvm-config` on PATH)

### Building from Source
```bash
cd endc
cargo build
```

### Running the Full Local Audit Suite
Before opening a PR, ensure all 8 quality gates pass locally:
```bash
cargo run --manifest-path endc/Cargo.toml --bin final_evidence_auditor
```

## 🤝 How to Contribute

1. **Fork the Repository** on GitHub.
2. **Create a Feature Branch:** `git checkout -b feature/amazing-feature`
3. **Run Local Quality Gates:** `cargo run --manifest-path endc/Cargo.toml --bin final_evidence_auditor`
4. **Commit your Changes:** `git commit -m 'feat: add feature X with golden test and contract evidence'`
5. **Push to the Branch:** `git push origin feature/amazing-feature`
6. **Open a Pull Request!** All 8 CI checks must pass before merge.
