## ⚡ Quick Install

### Windows (PowerShell One-Liner):
```powershell
irm https://raw.githubusercontent.com/IrMaho/End/main/install.ps1 | iex
```

### Windows (Offline / Direct Setup):
Download and run **`install.bat`** from the assets below!

### Linux & macOS (One-Liner):
```bash
curl -fsSL https://raw.githubusercontent.com/IrMaho/End/main/install.sh | sh
```
